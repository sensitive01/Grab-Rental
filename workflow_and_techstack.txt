Project: Grab Rentals - Car | Van | Bus Rental Booking Web Application

======================================
1. TECHNOLOGY STACK
======================================
Frontend (Current Focus):
- Framework: Next.js (React JS)
- Styling: Vanilla CSS / CSS Modules (Premium aesthetics)
- Deployment: Vercel / Netlify (for frontend preview)

Backend (Future Phase):
- Framework: Java (Spring Boot recommended)
- Database: PostgreSQL / Supabase
- API: RESTful / GraphQL API for communication between frontend and backend

======================================
2. MODULES & WORKFLOW
======================================
The application will consist of the following main portals/modules:

Module A: Website (Public Facing)
- Workflow: Landing Page -> Search availability (Outstation, Local, Airport) -> View Vehicles (Cars, Vans, Buses) -> Pricing & Details.
- Focus: SEO, Marketing, Lead Generation.

Module B: Customer Booking Portal
- Workflow: Login/Register -> Select Trip Details -> Choose Vehicle -> Enter Passenger Details -> Payment Gateway Integration -> Booking Confirmation -> View/Manage Bookings History.

Module C: Travel Agency / Fleet Owner Portal
- Workflow: Login -> Dashboard -> Add/Manage Vehicles (Cars, Vans, Buses) -> Manage Availability/Pricing -> View Assigned Bookings -> Accept/Reject Trips -> Track Revenue.

Module D: Admin Portal
- Workflow: Super Admin Login -> Dashboard -> User Management (Customers, Agencies, Operations) -> System Configuration -> View Platform Reports & Analytics -> Manage Payments/Commissions -> Content Management (CMS).

Module E: Operations Login
- Workflow: Operations Staff Login -> Manage Day-to-Day Bookings -> Assign Drivers/Vehicles -> Handle Customer Queries -> Monitor Active Trips.

======================================
3. FRONTEND DEVELOPMENT PHASES (Immediate Action)
======================================
Phase 1: Setup & Design System
- Initialize Next.js project.
- Setup global CSS, premium color palette, typography, and responsive grid.

Phase 2: Public Website (Savaari Clone style)
- Build Navbar, Hero Banner, Footer.
- Build the core "Booking Card" for Outstation, Local, and Airport trips.

Phase 3: Customer Portal (UI only)
- Create login/signup screens.
- Create vehicle listing/selection UI.
- Create booking summary and user dashboard UI.

Phase 4: Partner & Admin Portals (UI only)
- Create layouts and basic screens for Fleet Owners, Admin, and Operations dashboards.
